# Post views

An independently identified Post views. Per-Post log, recorded automatically.

## Information kept

- **Visit times** — Recorded non-owner HTML request times for the selected writing.
- **Daily counts** — Derived request counts grouped into the displayed 25 calendar-date buckets.
- **Total views** — Total recorded requests for the selected writing, rather than unique visitors.
