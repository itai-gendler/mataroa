# Post Backup

An independently identified Post Backup. Independently addressable; no Post association or restoration ability is established.

## Information kept

- **Title** — Saved editor title, using Untitled when blank.
- **Content** — Cleaned saved editor text, independent of any live writing instance.
- **Saved time** — Time the capture was created.
